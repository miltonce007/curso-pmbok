Casos Prácticos en Proyectos de Tecnología

Caso 1: Migración a la Nube de un Banco (Enfoque Híbrido)

Escenario: Un banco tradicional requiere migrar sus servicios a AWS cumpliendo regulaciones estrictas de ciberseguridad.

Dominio PMBOK Aplicado: Gestión del Riesgo e Incertidumbre, Dominio de Entrega.

Resolución: Se implementa un marco híbrido: desarrollo ágil (Scrum) para las integraciones de API y enfoque predictivo (Cascada) para auditorías de seguridad y cumplimiento normativo.

Caso 2: Fallo de Integración en Sistema ERP

Escenario: Un proyecto TI con alcance ambiguo sufre desviaciones graves de tiempo y sobrecostos.

Dominio PMBOK Aplicado: Dominio de Interesados y Planificación.

Resolución: Alineación activa de *stakeholders*, definición de un MVP (Producto Mínimo Viable) y control estricto de cambios mediante tablero Kanban.
